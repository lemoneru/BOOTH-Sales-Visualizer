# BOOTH Sales Visualizer

BOOTHからダウンロードできる売上データ（CSV）を可視化・分析するブラウザベースのツールです。

📊 **[ツールを開く (Webアプリ版)](https://lemoneru.github.io/BOOTH-Sales-Visualizer/)**

---

## 概要
売上CSVファイルをドラッグ＆ドロップするだけで、以下の分析が可能です。

* **KPIサマリー**: 期間の売上合計・注文数・平均単価・リピーター数をひと目で
* **月別の売上**: 月ごとの推移に加えて**前月比・前年同月比**を自動計算
* **累積売上の推移**: 商品ごとの積み上がりを1つのグラフで
* **商品別の内訳**: 構成比ランキングと直近90日の**伸び率**、バリエーション別の展開
* **売れる時間帯マップ**: 曜日×時間帯のヒートマップ（発売直後のブースト除外オプションあり）
* **ショップ・インサイト**: 最高売上日、ロケットスタート、ゴールデンタイム、リピーター数などを自動抽出

期間フィルタ（直近6/12ヶ月・年別・任意期間）、金額/個数の切り替え、グラフの画像保存、SNS共有用の**数値マスク**、ライト/ダークテーマに対応しています。

## セキュリティについて
**本ツールは、すべての計算・グラフ描画をブラウザ内（ローカル環境）で行います。**
読み込んだCSVデータが外部サーバーに送信されたり、保存されたりすることは一切ありません。

## 使い方
1. BOOTHの[売上管理画面](https://manage.booth.pm/sales/csv_requests)からCSVを発行・ダウンロード
   （絞り込み日時「注文日時」・状態「支払済み・発送完了」・期間は月ごとがおすすめ）
2. [Webアプリ](https://lemoneru.github.io/BOOTH-Sales-Visualizer/)を開く
3. 画面にCSVをドラッグ＆ドロップ（複数月まとめてOK）

手元にデータがなくても、トップページの「**サンプルデータで試してみる**」ボタンで動作を確認できます。

## 補足: 複数商品の注文について
BOOTHのCSVは、1回の注文に複数の商品が含まれると2行目以降の「注文日時」等が空欄になります。
本ツールは同じ注文番号の行から日時を引き継いで集計するため、**売上管理画面の合計と一致**します（v41で修正）。
