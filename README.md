# BOOTH Sales Visualizer

BOOTHからダウンロードできる売上データ（CSV）を可視化・分析するブラウザベースのツールです。

📊 **[ツールを開く (Webアプリ版)](https://lemoneru.github.io/BOOTH-Sales-Visualizer/)**

---

## 概要
売上CSVファイルをドラッグ＆ドロップするだけで、以下の分析が可能です。

* **全体グラフ**: 累積売上の推移を表示
* **ショップ・インサイト**: 最高売上日、ロケットスタート（時間最大注文）、リピーター数などを自動抽出
* **詳細分析**: バリエーション別、商品別の売上構成比
* **時間・曜日分析**: 売れやすい時間帯のヒートマップ（初動ブースト除外機能あり）

## セキュリティについて
**本ツールは、すべての計算・グラフ描画をブラウザ内（ローカル環境）で行います。**
読み込んだCSVデータが外部サーバーに送信されたり、保存されたりすることは一切ありません。
インターネット接続を切った状態（オフライン）でも動作可能です。

## 使い方
1. BOOTHの売上管理画面からCSVをダウンロード
2. [Webアプリ](https://lemoneru.github.io/BOOTH-Sales-Visualizer/)を開く
3. 画面にCSVをドラッグ＆ドロップ
